# Durni - Colombia Imparable

Durni es un chatbot de WhatsApp diseñado para gestionar el programa de aceleración rural de **Colombia Imparable**.

## Objetivos del Proyecto
- Gestión automatizada de participantes.
- Soporte y acompañamiento vía WhatsApp.
- Coordinación del programa de aceleración rural.

## Estructura del Proyecto
- `/src`: Código fuente del chatbot.
- `/docs`: Documentación y flujos de conversación.
- `/assets`: Recursos visuales y multimedia.
